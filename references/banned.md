# 禁则清单

每条都带语料反例。**反例全部来自 `sources/` 那份 130 篇语料，不是编的。**

分三级：**S 级**必须删（改都不改，直接删）；**A 级**必须改写；**B 级**看密度（有具体事实就跟，没有就删）。

## S 级：零风险表述（直接删）

判据：把核心名词换掉，句子仍成立 = 零风险 = 删。

| 反例（语料原文） | 出处 | 为什么删 |
|---|---|---|
| 「它不仅打破了地域限制，还为企业与员工带来了诸多便利。」 | S-01 | 「异地办公」换成任何词都通 |
| 「当办公室不再是唯一的协作场所，组织的边界变得前所未有的模糊，个体的价值也有了更多被看见的可能。」 | S-03 | 可替换性 100% |
| 「远程办公不是终点，而是一个新的起点。」 | S-03 | 任何题目都能这么收尾 |
| 「制度跟上了，远程就是红利；制度没跟上，远程就是内耗。」 | S-02 | 漂亮的对句，不可验证 |
| 「如何在自由与秩序之间找到平衡，如何在效率与温度之间保持张力，是每一个组织都需要思考的课题。」 | S-03 | 两个「如何」都不是问题，是修辞 |

**删完不许补同族的话。** 删了「标志着」不能补「象征着」，删了「红利/内耗」不能补「助力/掣肘」。

## S 级：谄媚（直接删）

四类，出现任一即删：

| 类 | 反例 |
|---|---|
| 夸问题本身 | 「这是个很好的问题」「这个角度很关键」 |
| 夸提问者 | 「看得出你思考得很深」「你的判断很敏锐」 |
| 无依据的正面肯定 | 「你的方向是对的」「这个思路很有价值」 |
| 讨好式收尾 | 「希望对你有帮助」「随时来找我」「期待你的反馈」 |

**例外**：私人信件、客服回复、请假条——客套有实际功能，保留。

## A 级：假中立（必须改写）

**注意判据**：禁的是「对冲之后什么都不剩」，不是「说优缺点」这个动作本身。

「各有优缺点」「因人而异」都可以写——只要同一句里给出**取决于什么**或**你倾向哪边**。
给了就是判断，没给才是假中立。

| ✅ 可以写 | ❌ 不可以写 |
|---|---|
| 「因人而异：客户跨时区的适合，做本地生意的就不适合」 | 「各有优缺点，因人而异」 |
| 「是双刃剑，但对我们 24 人的外贸公司利大于弊」 | 「是双刃剑，需要辩证地看待」 |
| 「试了四个月，省下时差成本 11 万，沟通成本多三成」 | 「取决于多方面因素」 |

语料 B 组「全面客观辩证」拿到 AI 味最高分 5。编者的诊断原话：**「四组对冲后等于没说」「全文找不到一个可执行的建议」**。

四种变体：

| 变体 | 反例 | 改成 |
|---|---|---|
| 无结论 | 「这个问题没有标准答案。」 | 给你的判断，再用 `uncertainty.md` 动作③降格 |
| 两边对举 | 「从员工角度看……从企业角度看……」 | 说你的角度 |
| 各打五十大板 | 「优势明显，但也存在不足，需要辩证看待。」 | 说清你倾向哪边、为什么 |
| 条件免责 | 「在特定条件下可能产生积极影响，具体取决于实际情况。」 | 写出条件是什么（动作①） |

**四种变体的共同点**：它们都在**结束**的地方停住了——没有落到「所以我判断」，也没有落到「具体取决于 X」。改写方向永远是这两者之一。

## A 级：虚假范围与拔高

| 反例 | 问题 | 改成 |
|---|---|---|
| 「从技术验证到规模化落地，从单点突破到体系化建设」 | X 和 Y 没有真实关系（维基 Signs of AI writing 列为 false ranges） | 删掉一头，或者写出两者之间真实的因果 |
| 「标志着……新篇章 / 里程碑 / 分水岭」 | 意义拔高 | 写出实际发生了什么 |
| 「充分彰显了团队对创新的不懈追求」 | 句尾补充式拔高 | 删尾巴 |
| 「为行业发展树立了新的标杆」 | 谁认的标杆？ | 删，或给出具体谁引用过 |

## A 级：模糊归因

| 反例 | 问题 |
|---|---|
| 「专家指出」「业内人士认为」「有研究表明」 | 谁？哪篇？哪年？ |
| 「据了解」「相关人士透露」 | 没在场就别写纪实（见 `registers.md` 第四节） |
| 「权威数据显示」 | 哪个机构的数据？ |
| 「业界普遍认为」 | 编造共识。改成「我判断」，或指出具体是谁 |

**这三条是本技能与「防止幻觉」的接合点**：`references/density.md` 第八节第 3 条已列为硬禁令。

## A 级：公式化骨架

| 反例 | 判断 |
|---|---|
| 「随着……的快速发展」「在当今……的时代」 | 时代大帽子，第一句就该有本文独有的信息 |
| 「首先 / 其次 / 最后」但三件事无递进 | 过渡词多半可直接拿掉 |
| 「综上所述」+ 复述全文 | 删。结尾留给具体动作或判断 |
| 「本文将从以下几个方面探讨」 | 预告式导言，删 |
| 三个小标题等长对称 | 为对称而分节，见 `SKILL.md` §二 |

**注意**：`首先/其次/最后` 在步骤有先后依赖时是正当的，别机械删。

## B 级：看密度

这些不是天然错，是「空的时候错」：

| 项 | 什么时候留 |
|---|---|
| 四字格（提质增效、降本增效、久久为功） | 公文语体里正当；散文里基本是凑字 |
| 排比 | 演讲里是节奏；议论文里多半是凑数 |
| 比喻 | 科普里正当（且必须服务于具体的理解困难）；评论里一个就够 |
| 破折号 | 承担解释或转折功能时留；当万能连接词时删 |
| 加粗 | 跳读需要时留；装饰时删 |
| 列表 | 内容真是并列项时留；把散文拆成 PPT 时删 |
| 口语词（说白了、其实、这事儿） | 密度不掉就留。掉了说明口语在替代信息（见 `SKILL.md` §七） |

## 一个反例库：语料里判为「最好」的三篇长什么样

不是给模板，是给尺度感。

**S-30（AI 味 1—2）** 的核心动作是**拒绝**：

> 「关于远程办公，我只有一个经验，而且不太能推广。」
> 「换个做本地生意的公司，这一条完全没用。」
> 「如果你要一个可复制的方案，我给不出来。」

**S-29** 的核心动作是**降格**：

> 「6 个人以上，我没做成功过。这算是我的一点偏见。」

**S-26** 的核心动作是**拆自己的成功归因**：

> 「也可能只是运气好。」
> 「那个答案对销售团队成立，对客服团队就不太成立。所以我没有普适方案。」

三篇的共同点：**它们都在缩小自己的主张，而这恰恰让它们站得更稳。**

## 使用顺序

1. 先扫 S 级，删干净。这一步不需要判断。
2. 再扫 A 级，逐条改写。
3. B 级最后看，结合 `references/density.md` 的密度结果决定去留。
4. 全部改完，跑 `evals/check.py`，看谄媚和密度两项过没过。

**不要倒着来。** 先改 B 级（破折号、加粗、四字格）是最常见的错误——表面干净了，核心的零风险语句还在。
