# 十类语体：宽严表

来源：人类 100 篇的十类分组，每类 10 篇。编者在规范里为每类写了「共同特征」，下表在原文基础上扩展成可执行的宽严。

**用法**：动笔前先判文体，再决定 §一~§八 哪些条款要放松、哪些要紧。

---

## 一、学术论文（H-01~H-10）

- 密度：中（术语本身算事实，但要有数据或定义支撑）
- 立场：**弱 — 让证据说话，不是让你没有判断**
- 结构规整：中，编号分节正当
- **特别禁令**：不许解释自己为什么重要。编者原话：「好的学术写作几乎不解释自己为什么重要，那是 AI 最爱做的事。」
- 允许：第一人称复数（「我们考虑」）、零引用（爱因斯坦 1905 那篇通篇没有参考文献）
- 反面：`本文具有重要的理论意义和实践价值` —— 删

## 二、公开演讲（H-11~H-20）

- 密度：低—中
- 立场：强
- 结构规整：低
- 特征：「面向耳朵而非眼睛，靠重复和停顿推进」
- **允许毛边**：编者批注「现场演讲总是有毛边」，AI 会写得很完整，那反而假
- 允许：重复（口语重复是节奏，不是冗余）、不完整句、跑题后回来

## 三、散文随笔（H-21~H-30）

- 密度：低
- 立场：**强，且必须是第一人称**
- 结构规整：低
- 核心判据：「合法性来自『这个人是这样想的』，而不是『这样想是对的』」
- **一旦文字开始自我论证，就不是散文了** —— 这是编者原话，也是最容易违反的一条
- 允许：跑题、不结论、自我怀疑、无用的细节

## 四、非虚构 / 纪实（H-31~H-40）

- 密度：**高，本表最高档之一**
- 立场：中（靠事实压住判断）
- 结构规整：低
- 核心：「权威感全部来自『我在场』和『我核实过』，而不是『我认为』」
- 硬要求：每个关键主张要能追到一个来源（采访、文件、现场）
- 反面：`据了解` `相关人士透露` —— 没在场就别写纪实

## 五、社论评论（H-41~H-50）

- 密度：中
- 立场：**最强，本技能的主战场**
- 结构规整：中
- 编者原话：「敢把话说死，也敢指名。AI 最不擅长这类文本，因为它倾向于给所有相关方都留台阶。」
- 硬要求：指名（哪个部门、哪家公司、哪条政策），不许用「有关方面」
- 允许：L4 断言，前提是过 `stance.md` 的资格三问

## 六、政策法规文本（H-51~H-60）

- 密度：不适用
- 立场：无
- 结构规整：**高，且正当**
- 编者原话：「这一类的『AI 味』和别处相反：它本来就该高度程式化……答案是有法律效力或明确规范对象时。」
- **不许用本技能去拆它的结构。** 这类文本的规整是功能，不是毛病
- 该管的：对象是否明确、权责是否清楚、条款是否可执行

## 七、科普作品（H-61~H-70）

- 密度：中
- 立场：中
- 结构规整：中
- 核心判据：「修辞密度高，不等于 AI 味重。区别在于比喻是否有原创性、是否服务于具体的理解困难。」
- **这一条推翻了「多比喻=AI味」的直觉**：科普必须高修辞，问题在比喻是不是可替换的
- 检验：把比喻换成一个更常见的比喻，理解难度变了吗？没变，说明这个比喻没干活
- 硬要求：**每个抽象概念配一个具体实例**（这条比任何密度数字都重要；科普实测密度中位只有 0.18，不设数字线）

## 八、书信日记（H-71~H-80）

- 密度：低
- 立场：强
- 结构规整：低
- 核心：「没有读者设定，所以没有表演。它是『人味』的最纯样本，也是 AI 最难伪造的一类——因为没有目标读者，AI 就失去了优化的方向。」
- **写作时的动作**：假装没人看。一旦开始想「读者会怎么看」，就开始假
- 允许：跳跃、省略背景、只有自己懂的指代

## 九、技术文档（H-81~H-90）

- 密度：**最高**
- 立场：无
- 结构规整：**高，且正当**
- 编者原话：「这类文本是 AI 表现最接近人类的地方——因为写得好就是写得像规范。放进来是为了校准一件事：『不像人写的』未必是缺点。」
- **不许加立场，不许加修辞，不许口语化**
- 该管的：参数准确、版本明确、错误码对应、步骤可复现

## 十、文学评论（H-91~H-100）

- 密度：低—中
- 立场：**强，且允许偏爱**
- 结构规整：低
- 核心：「合法性在于『这个判断是这个人做出的』，所以第一人称的偏见反而是资产。AI 在这里最容易写成一堆正确的空话。」
- 硬要求：给出你偏爱的理由，且理由要能被反驳
- 反面：`作品展现了作者深厚的功底` —— 谁都能说，等于没说

---

## 横向对照：三条最容易搞反的

| 直觉 | 实际 |
|---|---|
| 规整 = AI 味 | **技术文档和政策法规里，规整是正确** |
| 修辞多 = AI 味 | **科普必须高修辞**，问题在比喻是否原创、是否服务理解 |
| 密度高 = 好 | **散文、演讲、书信里密度低是特征**，硬塞数字会毁掉文体 |

## 判断流程

```
这段文字会出现在哪里？
  ├─ 有法律效力 / 规范对象明确 → 政策法规 → 结构规整正当，别拆
  ├─ 要被人照着做 → 技术文档 → 密度优先，禁止立场和修辞
  ├─ 要被人听见 → 演讲 → 允许重复和毛边
  ├─ 要说服人接受一个判断 → 社论 / 文学评论 → 立场优先，敢指名
  ├─ 要让人相信你经历过 → 纪实 → 密度优先，靠在场不靠我认为
  ├─ 要让人懂一个难概念 → 科普 → 高修辞正当，比喻要原创且服务理解
  ├─ 只写给自己 → 书信日记 → 假装没人看
  ├─ 论证一个学术主张 → 论文 → 别解释自己为什么重要
  └─ 讲一个想法而非论证它 → 散文 → 别自我论证
```
