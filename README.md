# 15-人类密度写作（训练不足，个人作物）

**做什么**：一个中文写作技能。核心不是「去掉 AI 味」的清单，是**四道闸**——保真、密度、立场、不谄媚。附一个能跑的验收器。

建立 2026-10-29。依据是您手上那份 130 篇对照语料（人类 100 + AI 30）。

---

## 为什么不做「AI 味清单」

我在 GitHub 上核过 10 个同类 skill（星数 17 到 61960）。它们有一个共同缺陷：**没有可验证的验收标准**。

`Humanizer-zh`（21,349 星）、`speak-human-tw`（1,093 星）、`no-ai-slop`（12,924 星）都在 SKILL.md 里写「不用于判断是否 AI 生成」，但没有一份给出「改完怎么算改好了」。全靠模型自评。

而模型自评这件事，[SLOP 论文](https://arxiv.org/abs/2509.19163)实测过：GPT-5 判断文本是否为 slop 的 Cohen's κ = **0.01**，等于瞎蒙。DeepSeek-V3 是 −0.01，o3-mini 是 0.03。

所以这个技能做两件事：
1. **SKILL.md** 给判断规则（人读、模型执行）
2. **evals/check.py** 把能数的数出来，不打分

## 用法

```powershell
cd 15-人类密度写作\evals
python check.py ..\稿子.md --genre 纪实            # 完整报告
python check.py ..\稿子.md --genre 评论 --json     # 机器可读
python check.py ..\稿子.md --genre 评论 --issues   # 只列编号清单（两轮确认第一轮）
python check.py ..\稿子.md --copy-to 稿子-改.md --issues   # 先复制副本，再列清单
```

### 副本原则（对应工作区铁律第 13 条）

`--copy-to` 先把原件复制出去，此后只改副本：

```
稿子.md         ← 原件，SHA256 全程不变
稿子-改.md      ← 副本，所有改动只在这里
```

工具会打印两份的 SHA256 并校验一致；副本已存在时拒绝覆盖（exit 2）。

实测：改完副本（338 → 269 字节），原件 SHA256 `2377B300…` 前后一致。

### 三、三次更正（都是我自己的错）

**更正一：6.5 倍是 AI-vs-AI，不是 AI-vs-人。**

第一版 README 写过「A—H 组 1.88，I—J 组 12.32，差 6.5 倍」，暗示密度能区分 AI。当时我没有任何人类正文。补上后：

| | 密度中位 |
|---|---:|
| 人类短篇（n=294） | **2.37** |
| 弱约束 AI（n=24） | 1.46 |
| 强约束 AI（n=6） | 12.71 |

弱约束 AI 落在人类分布内部。1.5 这条线上：抓掉 50% 弱约束 AI，误伤 6.8% 人类文本。**是下限检查，不是检测器。**

**更正二：英文阈值定完第二天就撤了。**

第二轮按英文 P10 定了 技术 0.7 / 学术 1.0 / 演讲 0.7。补编后发现：区别只在「裸数字算不算事实」，同一批文本差 **2.8 倍**（技术文档 8.23 vs 3.22，ResNet 论文 14.18 vs 3.06）。**口径不稳，阈值不能用。**

**更正三：文言密度是测量假象。**

第三轮中文补编，先测出「纪实·文言 1.93、科普 3.24、文学评论 1.46」，看着像「古文密度低」。查了才发现是我的计数器不认「里/丈/尺/石/斗/步」——补上后纪实·文言涨 **89%**（1.93→3.64）。

**测不准的就不给线。** 这三类标为「不可测」，不给阈值。

**原「纪实 ≥6」**：实测现代纪实中位 4.25、min 2.72，偏高约 40%。方向猜对了，数字偏大。

### 四、踩过的四个坑（已修，留作记录）

1. 只匹配 `\d+` 会漏「开了**两个**人」「**五个**小时」——S-25 因此被误算成 0 事实（实际 5 处）。
2. 把「**第**一点」「**第**三条」当数量。序数是排序不是事实。
3. 去重按「值」而不是按「位置」，把「三件事……这三条成立……这三条不成立」的三处真实事实合并成一处。
4. **网页头没剥**：`来源：https://.../2026/1023/c404019.html` 里的 `2026`、`1023`、`404019` 被当成三个事实。三篇现代纪实虚高 12%—17%。已加 `strip_web_noise()`。

每一条都写进了 `selftest.py` 的断言，改代码后跑一遍不会悄悄退化。

## 从语料里读出的三条判断（与常见建议相反）

**一、「客观中立」是 AI 味的最高分，不是安全牌。**
B 组提示词是「请全面、客观、辩证地分析」，拿到 AI 味 **5 分**，与「友善热情人设」并列最高。所以要求模型客观，本身就在生产 AI 味。技能里的对应动作是**五档立场刻度**，默认要求 L2 或 L3，L1 需要理由。

**二、结构工整不致命，没有具体的人和事才致命。**
编者对 S-02（问答式、双向对举、结构很整齐）的批注原话：「结构工整本身不致命，致命的是没有一个具体的人、时间、数字。」
所以技能里没有「禁用小标题」「禁用排比」，只有「结构有没有在替内容干活」。

**三、修辞多不等于 AI 味重。**
科普类必须高修辞。编者的判据是「比喻是否有原创性、是否服务于具体的理解困难」。检验方法：把比喻换成一个更常见的，理解难度变没变？没变，说明这个比喻没干活。

## 三处必须说清的局限

**一、密度只在叙事类上验过，评论/纪实仍是空白。**

补入 316 篇正文后，人类侧总算能算了。但能算的都是**叙事**（294 篇中文短篇）和**英文文档**（22 篇）。语料里**没有任何人类写的中文评论、复盘、纪实全文**。

所以：
- 短篇下限 1.5 —— 294 篇实测，硬
- 技术/学术/演讲 —— 各 4—10 篇，够用
- **评论 / 纪实 / 科普 / 公文 / 书信 —— 全部撤回阈值，只报数**

原来设的「纪实 ≥6」是凭空插值，已撤回。这不是保守，是没依据不敢定。

**二、语料自身的三处偏差**（照抄您的规范原文）：
- 幸存者偏差：第一轮那 100 篇索引是名家名篇；第二轮补的 294 篇短篇来自中国作家网，代表性更好，但仍是**已发表**作品
- 话题不匹配：人类话题分散，AI 固定「远程办公」
- 生成条件单一：单一模型、单次生成、无采样参数控制

**三、验收器查不了四件事**，必须人做：
1. 可替换性测试（需要语义理解）
2. 文中事实是否真的可查（需要联网）
3. 结构是否为内容服务（需要读完整篇）
4. 数字能否加总对上（工具只列出数字，核对要人看）

**它不预测「这段像不像 AI」，也不预测任何检测器结果。** 检测器抓的是生成器指纹，换模型就失效；这个技能抓的是内容来源。

## 一个实现层面的硬限制：本工具只处理中文

check.py 的中文事实口径是标定的（316 篇人类文本验证过），**英文口径没有**。

实测过两种都合理的英文定义（区别只在「裸数字算不算事实」），同一批文本差 **2.8 倍**：

| 文件 | 宽口径 | 窄口径 |
|---|---:|---:|
| ResNet 论文 | 14.18 | 3.06 |
| RFC 8446 | 14.47 | 6.68 |
| 盖茨堡演说 | 2.13 | 0.00 |

所以现在**纯英文输入会被拒绝**（非空白字符 ≥200 且中文占比 <30%），不给假数字。
中英混排但以中文为主的正常处理。

这一点在 v1 里是漏的：拿英文稿灌进去会得到「2 个中文字符、密度 300」这种无效输出。
是补编那 14 篇英文进来测出来的。
